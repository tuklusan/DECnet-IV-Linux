# Handover

This is the stable resume entry point for DECnet-IV-Linux.

1. Read `docs/PROJECT_STATE.md` completely. Its `Resume point` and `Next action` describe the live repository state.
2. Read `docs/ROADMAP.md` completely and confirm the next action follows the ordered dependency plan.
3. Read `docs/ARCHITECTURE.md` and `docs/TEST_LAB.md` before changing architecture, image construction or acceptance tests.
4. This is a single-developer repository. Work directly on the current `main` HEAD. Do not create pull requests or development branches; preserve useful historical refs only as inert aliases.
5. After any change, restart the SoP sequence from the complete latest repository copy. Delivery requires three consecutive clean full passes.

Repository files are authoritative. Do not reconstruct current state from chat history or from stale workflow runs.
